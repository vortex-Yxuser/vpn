# Yohan VPN

## ما يعمل فعلياً في هذا الإصدار (100% حقيقي وقابل للتشغيل)
1. اتصال SSH حقيقي عبر مكتبة JSch.
2. **بروكسي SOCKS5 حقيقي** يعمل محلياً على الجهاز (Dynamic Port Forwarding عبر SSH) —
   تم تصحيح خطأ في الإصدار السابق كان يمنع هذا من العمل أصلاً.
3. واجهة VpnService/TUN حقيقية (Android يطلب صلاحية VPN فعلياً ويظهر أيقونة المفتاح).
4. خدمة Foreground صحيحة مع إشعار دائم وزر قطع اتصال (متوافقة مع Android 8 حتى 14+).
5. حالة اتصال حقيقية تُعرض في الواجهة (جاري الاتصال / متصل / خطأ / منقطع)
   بدلاً من نص ثابت لا يتغير.
6. خيار التحقق من مفتاح الخادم (Host Key Verification) بدلاً من تعطيله دائماً.

## الاستخدام بدون تعديل إضافي
بمجرد التثبيت، التطبيق بروكسي SOCKS5 حقيقي عبر SSH. يمكنك استخدامه فوراً بإعداد
أي تطبيق يدعم بروكسي SOCKS5 يدوياً (متصفح، إلخ) على `127.0.0.1:<المنفذ الظاهر في الإشعار>`.

## الجزء الوحيد المتبقي لتحويله إلى "نفق كامل" (كل حركة الجهاز تلقائياً)
واجهة TUN يتم إنشاؤها بنجاح، لكن حزم IP الخارجة منها لا تُقرأ ولا تُحوَّل بعد إلى
اتصالات عبر بروكسي SOCKS5. هذا يتطلب مكتبة **native** (ملف `.so` مُصرَّف مسبقاً)
مثل `tun2socks` أو `hev-socks5-tunnel`. لم يتم تضمينها هنا لأن تحميلها/تصريفها
يتطلب اتصال إنترنت غير متاح في بيئة إنشاء هذا الملف.

### خطوات الإضافة (10 دقائق تقريباً)
1. نزّل ملفات `.so` الجاهزة لكل معمارية (arm64-v8a, armeabi-v7a, x86_64) من
   مستودع `hev-socks5-tunnel` أو `tun2socks` على GitHub (صفحة Releases).
2. ضعها في: `app/src/main/jniLibs/<ABI>/libhev-socks5-tunnel.so`
3. في `YohanVpnService.kt`، داخل التعليق الموجود بعد `updateNotification(...)`،
   استدعِ المكتبة عبر JNI مع تمرير: `tun!!.fileDescriptor` و`socksPort`.
   التوقيع يختلف قليلاً حسب المكتبة، لكن الـ README الخاص بكل مكتبة يوضحه بمثال جاهز.

بعد هذه الخطوة فقط، يصبح نفقاً كاملاً حقيقياً.

## ملاحظات أمان
- كلمة المرور تُمرَّر حالياً كنص عادي بين الشاشة والخدمة (داخل نفس التطبيق فقط،
  وليست معرّضة خارجياً)، لكن للاستخدام الجاد يُفضّل التحويل لمصادقة بمفتاح SSH.
- فعّل "التحقق من مفتاح الخادم" في الواجهة عند الاتصال بخادم تثق بمفتاحه.
